#  Pokémon Memory Game  
A React + Vite memory game built as part of **The Odin Project** curriculum.  
Test your memory, race against the clock, and try to beat your fastest times!

---

##  Features

###  Memory Gameplay  
- Click each Pokémon **only once** to win.  
- Cards **shuffle on every click**, keeping the challenge fresh.  
- Game ends when you click a duplicate — or when you successfully select them all!

###  Difficulty Modes  
Choose how intense your memory workout should be:  
- **Easy** – 8 Pokémon  
- **Medium** – 12 Pokémon  
- **Hard** – 16 Pokémon  

Each mode fetches the correct number of Pokémon dynamically from the [Pokémon API](https://pokeapi.co/).

###  Timer + Leaderboard  
- Timer starts automatically when the game begins.  
- Your **fastest times** for each difficulty level are saved using **Local Storage**.  
- View your best performances in the built-in **Leader Board**.

###  Scoreboard  
- Displays **Current Score** and **Current Time** for the session  

---

##  Tech Stack

- **Vite**
